# RobloxHelperTimeBomb

Python-скрипт для механики **Timebomb** в Roblox. Нажатие WASD или стрелки дает 0,5 секунды движения, после чего эти клавиши блокируются на 2 секунды. `F1` включает и выключает отслеживание.

---

## ⚡ Особенности

- **Глобальные хоткеи:** Работает прямо в игре, даже когда окно Roblox находится в фокусе.
- **Окно движения:** WASD и стрелки запускают таймер движения на 0,5 секунды.
- **Блокировка:** После окна движения WASD и стрелки блокируются на 2 секунды.
- **Динамический таймер:** Отображает обратный отсчет в реальном времени на одной строке без засорения консоли.
- **Пробел:** Не запускает таймер и не блокируется.
- **Управление:** `F1` включает и выключает отслеживание.

---

## 🚀 Быстрый старт

### 1. Требования
Убедитесь, что у вас установлен Python версии 3.8 или выше.

### 2. Установка

Склонируйте репозиторий или скачайте файлы, затем установите зависимости:

```powershell
python -m pip install -r requirements.txt
python main.py
```

Для глобального перехвата клавиш в Windows может потребоваться запуск терминала от имени администратора.

### Сборка в EXE

```powershell
python -m pip install pyinstaller
python -m PyInstaller --onefile main.py
```

Готовый файл появится в папке `dist`.
